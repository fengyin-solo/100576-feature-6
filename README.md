# 变电站继电保护定值整定与二次设备检修管理平台

面向变电站台账、保护装置、定值整定与核对、二次回路检查、保护校验、故障录波分析、主变检修与直流系统监测的一体化电网二次设备运维管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `substation-protection:entries` 这一项，或调用 `resetModule(模块)`。

## 变电站归属与权限

变电站台账在通用流转之外多一层归属收权，规则集中在 `frontend/src/api/substation-domain.ts`，
页面不做业务判断：

- **归属口径**：一座站挂在哪个供电所名下，以**最近一次已办结的移交记录**为准；没有移交记录时
  沿用台账「所属供电所」的既有口径。列表页与详情抽屉共用同一份 `stationView`，两处站名、归属
  永远一致；台账原口径与移交记录冲突时，列表与抽屉都会标出冲突并按移交记录显示。
- **谁能改**：只有归属供电所的值班人能改「站名、电压等级、接线方式」与办理投运/检修/退役。
  改动以「申请—办结/退回」方式走流水，办结才写入台账；退回必须写明理由。别所值班人只能查看，
  越权提交一律退回（消息里写明归属所与理由），并在该站台账流水里留一条越权记录。
- **退役办结**：退役申请由归属所发起，同一座站重复提交只落一条；办结后站状态置为「已退役」，
  整条台账锁为只读（归属所自己也不能再改），并向**工作票许可**的待办理清单（待签发）落一条
  `RET-<站编号>` 工作票，重复办结不会重复落单。
- **交接班**：没办结的改动/退役申请跟着**同所接班人**走（经办人改为接班人），原经办人栏
  （`createdBy`）永久保留在台账流水里；跨所不能交接。
- **归属移交**：由当前归属所发起、提交即生效，在办事项一并转给接收所值班人继续办理。

顶栏可切换当前值班人身份（仅用于演示越权/收权效果，不触发交接；在办事项跟随请走台账页的
「交接班」）。值班人与供电所名册在 `frontend/src/data/org.ts`。
